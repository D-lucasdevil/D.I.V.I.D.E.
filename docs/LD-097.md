    <!-- OVERVIEW -->
    <div class="section-label">// Overview //</div>
    <div class="block">
      <p>LD-097, designated <strong>“The Cannibalistic Meat Cleaver,”</strong> is an anomalous butcher's cleaver composed entirely of unidentified biological material.</p>
      <p>The handle appears to consist of fused bone, cartilage, and dense muscle tissue, while the blade itself appears to have been formed from an extremely dense and unusually sharp bone-like substance.</p>
      <p>Despite its organic appearance, LD-097 does not decay, produce biological waste, or display any conventional signs of metabolism.</p>
      <p>The weapon is extraordinarily durable and appears to become progressively stronger through the <strong>consumption of human flesh by its wielder</strong>.</p>
      <p>Unlike several other anomalous weapons, LD-097 possesses <strong>no visible counter, display, meter, or other method of determining its accumulated strength.</strong></p>
      <p>Researchers therefore have no reliable method of determining how powerful LD-097 has become at any given time.</p>
    </div>

    <!-- ANOMALOUS INFLUENCE -->
    <div class="section-label">// Anomalous Influence //</div>
    <div class="block">
      <p>Upon voluntarily picking up LD-097, the wielder experiences an immediate psychological shift.</p>
      <p>The individual develops an intense desire to consume <strong>human flesh</strong>.</p>
      <p>Animal meat, synthetic food, and other biological materials do not satisfy the compulsion and produce no observed anomalous reaction.</p>
      <p>The effect becomes increasingly severe the longer LD-097 remains in the individual's possession.</p>
      <p>Early symptoms include:</p>
    </div>
    <div class="li"><span class="mk">▸</span>Increased hunger.</div>
    <div class="li"><span class="mk">▸</span>Intrusive thoughts concerning human flesh.</div>
    <div class="li"><span class="mk">▸</span>Irritability.</div>
    <div class="li"><span class="mk">▸</span>Fixation on human scent.</div>
    <div class="li"><span class="mk">▸</span>Increasing difficulty resisting the compulsion.</div>
    <div class="block" style="margin-top:8px;">
      <p>Extended exposure produces increasingly severe symptoms.</p>
      <p>Eventually, the wielder begins actively seeking opportunities to obtain human flesh.</p>
      <p>The psychological effect does not appear to constitute direct mind control.</p>
      <p>Individuals retain the ability to make decisions.</p>
      <p>However, resisting LD-097 becomes progressively more difficult.</p>
    </div>

    <!-- STRENGTH AMPLIFICATION -->
    <div class="section-label">// Strength Amplification //</div>
    <div class="block">
      <p>LD-097 becomes stronger whenever its wielder successfully consumes <strong>human tissue</strong>.</p>
      <p>The exact relationship between consumption and increased weapon strength remains unknown.</p>
      <p>Current evidence suggests:</p>
      <p><strong>More human flesh consumed = greater LD-097 output.</strong></p>
      <p>Only human tissue appears capable of feeding the weapon's anomalous properties.</p>
      <p>The cleaver itself shows no obvious physical change as its strength increases.<a class="rev" href="#addendum">REVISED — SEE ADDENDUM</a></p>
      <p>There is therefore <strong>no confirmed upper limit</strong> to its potential strength.</p>
    </div>

    <!-- OBSERVED EFFECTS -->
    <div class="section-label">// Observed Effects //</div>
    <div class="block">
      <p>At low levels of activity, LD-097 is already capable of functioning as an extremely effective cutting weapon.</p>
      <p>After prolonged feeding, recorded capabilities have included:</p>
    </div>
    <div class="li"><span class="mk">▸</span>Cutting heavy wooden doors.</div>
    <div class="li"><span class="mk">▸</span>Severing reinforced security equipment.</div>
    <div class="li"><span class="mk">▸</span>Damaging armored personnel equipment.</div>
    <div class="li"><span class="mk">▸</span>Cutting through structural concrete.</div>
    <div class="li"><span class="mk">▸</span>Splitting reinforced walls.</div>
    <div class="block" style="margin-top:8px;"><p>The maximum confirmed output remains unknown.</p></div>

          var x = rand(0.04, 0.96) * W, y = rand(0.04, 0.96) * H, ok = true;
          for (i = 0; i < eyes.length; i++) { var o = eyes[i], dx = o.x - x, dy = o.y - y, md = (o.r + r) * 1.9; if (dx * dx + dy * dy < md * md) { ok = false; break; } }
          if (ok) { px = x; py = y; break; }
        }
        var vs = [], nv = 6 + ((Math.random() * 4) | 0);
        for (i = 0; i < nv; i++) vs.push([rand(0, TAU), rand(0.45, 0.9)]);
        return {
          x: px, y: py, r: r, born: now, dying: false, dieAt: 0, ang: rand(-0.5, 0.5), ic: IRIS[(Math.random() * IRIS.length) | 0],
          blinkT: 0, nextBlink: now + rand(900, 4200), lx: 0, ly: 0, tx: rand(0, W), ty: rand(0, H), dart: now + rand(100, 500),
          ph: rand(0, TAU), vs: vs
        };
      }

      function resizeAll() {
        W = window.innerWidth; H = window.innerHeight;
        sc = clamp(Math.min(W, H) / 800, 0.7, 1.4);
        live.width = Math.floor(W * dpr); live.height = Math.floor(H * dpr);
        live.style.width = W + 'px'; live.style.height = H + 'px';
        lctx.setTransform(dpr, 0, 0, dpr, 0, 0);
        limbs = []; eyes = []; makeBulges();
        updateProgress();
      }

      /* limb drawing helpers */
      function seg(ax, ay, bx, by, w, col) {
        lctx.strokeStyle = col; lctx.lineWidth = w;
        lctx.beginPath(); lctx.moveTo(ax, ay); lctx.lineTo(bx, by); lctx.stroke();
      }
      function drawHand(l, x, y, ang, t, K, fm) {
        var r = l.w2 * 0.62, i;
        var offs = [-0.62, -0.22, 0.16, 0.52, 1.3], lens = [0.95, 1.1, 1.0, 0.82, 0.62];
        lctx.lineCap = 'round'; lctx.lineJoin = 'round';
        var pts = [];
        for (i = 0; i < 5; i++) {
          var a0 = ang + offs[i] * l.mir;
          var curl = (0.5 + 0.5 * Math.sin(t * fm * (0.8 + i * 0.15) + l.fph[i])) * K;
          var fl = r * 1.05 * lens[i], px = x + Math.cos(a0) * r * 0.5, py = y + Math.sin(a0) * r * 0.5;
          var arr = [px, py], aa = a0, j;
          for (j = 0; j < 3; j++) { aa += curl * (0.55 + j * 0.35) * l.mir; px += Math.cos(aa) * fl; py += Math.sin(aa) * fl; arr.push(px, py); }
          pts.push(arr);
        }
        var fw = r * 0.62;
        for (i = 0; i < 5; i++) { var p = pts[i]; lctx.strokeStyle = '#1d0407'; lctx.lineWidth = fw + 3; lctx.beginPath(); lctx.moveTo(p[0], p[1]); lctx.lineTo(p[2], p[3]); lctx.lineTo(p[4], p[5]); lctx.lineTo(p[6], p[7]); lctx.stroke(); }
        lctx.fillStyle = '#1d0407'; lctx.beginPath(); lctx.arc(x, y, r + 2.5, 0, TAU); lctx.fill();
        for (i = 0; i < 5; i++) { var q = pts[i]; lctx.strokeStyle = l.col; lctx.lineWidth = fw; lctx.beginPath(); lctx.moveTo(q[0], q[1]); lctx.lineTo(q[2], q[3]); lctx.lineTo(q[4], q[5]); lctx.lineTo(q[6], q[7]); lctx.stroke(); lctx.fillStyle = '#e8d8a0'; lctx.beginPath(); lctx.arc(q[6], q[7], fw * 0.32, 0, TAU); lctx.fill(); }
        lctx.fillStyle = l.col; lctx.beginPath(); lctx.arc(x, y, r, 0, TAU); lctx.fill();
        lctx.fillStyle = l.hi; lctx.globalAlpha = 0.4; lctx.beginPath(); lctx.arc(x - r * 0.25, y - r * 0.25, r * 0.5, 0, TAU); lctx.fill(); lctx.globalAlpha = 1;
      }
      function drawFoot(l, x, y, ang, t, K, fm) {
        var r = l.w2 * 0.78, i;
        lctx.save(); lctx.translate(x, y); lctx.rotate(ang + 0.3 * l.mir);
        lctx.fillStyle = '#1d0407'; lctx.beginPath(); lctx.ellipse(r * 0.6, 0, r * 1.5 + 3, r * 0.95 + 3, 0, 0, TAU); lctx.fill();
        for (i = 0; i < 5; i++) { var ty = (i - 2) * r * 0.42, tx = r * 1.8 + Math.sin(t * fm + l.fph[i]) * 3 * K; lctx.beginPath(); lctx.arc(tx, ty, r * 0.3 + 2.5, 0, TAU); lctx.fill(); }
        lctx.fillStyle = l.col; lctx.beginPath(); lctx.ellipse(r * 0.6, 0, r * 1.5, r * 0.95, 0, 0, TAU); lctx.fill();
        for (i = 0; i < 5; i++) { var ty2 = (i - 2) * r * 0.42, tx2 = r * 1.8 + Math.sin(t * fm + l.fph[i]) * 3 * K; lctx.beginPath(); lctx.arc(tx2, ty2, r * 0.3, 0, TAU); lctx.fill(); lctx.fillStyle = '#e8d8a0'; lctx.beginPath(); lctx.arc(tx2 + r * 0.18, ty2, r * 0.1, 0, TAU); lctx.fill(); lctx.fillStyle = l.col; }
        lctx.fillStyle = l.hi; lctx.globalAlpha = 0.35; lctx.beginPath(); lctx.ellipse(r * 0.4, -r * 0.3, r * 0.9, r * 0.35, 0, 0, TAU); lctx.fill(); lctx.globalAlpha = 1;
        lctx.restore();
      }
      function drawLimb(l, t, am, fm, K) {
        var R = 1 - Math.pow(1 - clamp(l.reach, 0, 1), 3);
        if (R <= 0.01) return;
        var jit = l.sp * Math.sin(t * 40 + l.p0) * 0.6;
        var a0 = l.a + Math.sin(t * l.f0 * fm + l.p0) * l.am0 * am + jit;
        var a1 = a0 + l.b1 + Math.sin(t * l.f1 * fm + l.p1) * l.am1 * am + jit * 1.3;
        var a2 = a1 + l.b2 * 0.6 + Math.sin(t * l.f2 * fm + l.p2) * l.am2 * am + jit * 1.6;
        var x0 = l.x, y0 = l.y;
        var x1 = x0 + Math.cos(a0) * l.L0 * R, y1 = y0 + Math.sin(a0) * l.L0 * R;
        var x2 = x1 + Math.cos(a1) * l.L1 * R, y2 = y1 + Math.sin(a1) * l.L1 * R;
        lctx.lineCap = 'round'; lctx.lineJoin = 'round';
        seg(x0, y0, x1, y1, l.w0 + 6, '#1d0407'); seg(x1, y1, x2, y2, l.w1 + 6, '#1d0407');
        lctx.fillStyle = '#1d0407'; lctx.beginPath(); lctx.arc(x1, y1, l.w1 * 0.55 + 3, 0, TAU); lctx.fill();
        seg(x0, y0, x1, y1, l.w0, l.col); seg(x1, y1, x2, y2, l.w1, l.col);
        lctx.fillStyle = l.col; lctx.beginPath(); lctx.arc(x1, y1, l.w1 * 0.55, 0, TAU); lctx.fill();
        var n0x = -(y1 - y0), n0y = (x1 - x0), nl0 = Math.sqrt(n0x * n0x + n0y * n0y) || 1; n0x /= nl0; n0y /= nl0;
        var n1x = -(y2 - y1), n1y = (x2 - x1), nl1 = Math.sqrt(n1x * n1x + n1y * n1y) || 1; n1x /= nl1; n1y /= nl1;
        seg(x0 - n0x * l.w0 * 0.2, y0 - n0y * l.w0 * 0.2, x1 - n0x * l.w0 * 0.2, y1 - n0y * l.w0 * 0.2, l.w0 * 0.28, l.hi);
        seg(x1 - n1x * l.w1 * 0.2, y1 - n1y * l.w1 * 0.2, x2 - n1x * l.w1 * 0.2, y2 - n1y * l.w1 * 0.2, l.w1 * 0.28, l.hi);
        lctx.strokeStyle = 'rgba(100,10,22,0.55)'; lctx.lineWidth = 1.4;
        lctx.beginPath(); lctx.moveTo(x0 + n0x * l.w0 * 0.15, y0 + n0y * l.w0 * 0.15); lctx.lineTo(x1 + n0x * l.w0 * 0.15, y1 + n0y * l.w0 * 0.15); lctx.moveTo(x1 + n1x * l.w1 * 0.15, y1 + n1y * l.w1 * 0.15); lctx.lineTo(x2 + n1x * l.w1 * 0.15, y2 + n1y * l.w1 * 0.15); lctx.stroke();
        if (l.leg) drawFoot(l, x2, y2, a2, t, K, fm); else drawHand(l, x2, y2, a2, t, K, fm);
      }

      function drawEye(o, now, t) {
        var grow = clamp((now - o.born) / 600, 0, 1);
        grow = 1 + 2.2 * Math.pow(grow - 1, 3) + 1.2 * Math.pow(grow - 1, 2);
        if (o.dying) grow *= clamp(1 - (now - o.dieAt) / 400, 0, 1);
        var R = o.r * grow; if (R < 1) return;
        var fast = 1 + 3 * e;

        if (now > o.nextBlink) { o.blinkT = now; o.nextBlink = now + rand(900, 4200) / (1 + e * 3.2); }
        var bl = (o.blinkT && now - o.blinkT < 170) ? Math.sin((now - o.blinkT) / 170 * Math.PI) : 0;
        var open = Math.max(0.07, 1 - bl);

        if (!calm && e > 0.18 && now > o.dart) { o.tx = rand(0, W); o.ty = rand(0, H); o.dart = now + rand(110, 420) / (0.6 + e * 2); }
        var tx, ty, lerp;
        if (mx >= 0 && (calm || e < 0.2 || Math.random() > e * 0.5)) { tx = mx; ty = my; lerp = 0.14; } else { tx = o.tx; ty = o.ty; lerp = 0.3; }
        var dx = tx - o.x, dy = ty - o.y, dl = Math.sqrt(dx * dx + dy * dy) || 1;
        var mag = Math.min(1, dl / (R * 4)) * R * 0.38;
        var cA = Math.cos(-o.ang), sA = Math.sin(-o.ang);
        var wx = dx / dl * mag, wy = dy / dl * mag;
        var lx = wx * cA - wy * sA, ly = wx * sA + wy * cA;
        o.lx += (lx - o.lx) * lerp; o.ly += (ly - o.ly) * lerp;

        lctx.save(); lctx.translate(o.x, o.y); lctx.rotate(o.ang);

        var sg = lctx.createRadialGradient(0, 0, R * 0.8, 0, 0, R * 2.3);
        sg.addColorStop(0, 'rgba(50,4,10,0.7)'); sg.addColorStop(1, 'rgba(50,4,10,0)');
        lctx.fillStyle = sg; lctx.beginPath(); lctx.arc(0, 0, R * 2.3, 0, TAU); lctx.fill();

        var rx = R * 1.32, ry = Math.max(R * 0.05, R * 0.92 * open);
        lctx.strokeStyle = 'rgba(214,138,128,0.55)'; lctx.lineWidth = R * 0.4;
        lctx.beginPath(); lctx.ellipse(0, 0, rx + R * 0.18, ry + R * 0.26, 0, 0, TAU); lctx.stroke();

        lctx.save();
        lctx.beginPath(); lctx.ellipse(0, 0, rx, ry, 0, 0, TAU); lctx.clip();
        lctx.fillStyle = '#e9dcc9'; lctx.fillRect(-rx, -ry, rx * 2, ry * 2);
        lctx.strokeStyle = 'rgba(176,26,36,0.6)'; lctx.lineWidth = Math.max(0.8, R * 0.05);
        for (var i = 0; i < o.vs.length; i++) {
          var va = o.vs[i][0], vl = o.vs[i][1];
          lctx.beginPath(); lctx.moveTo(Math.cos(va) * rx * 1.05, Math.sin(va) * ry * 1.05);
          lctx.lineTo(Math.cos(va + 0.15) * rx * vl, Math.sin(va + 0.15) * ry * vl); lctx.stroke();
        }
        var ir = R * 0.56;
        var ig = lctx.createRadialGradient(o.lx, o.ly, ir * 0.15, o.lx, o.ly, ir);
        ig.addColorStop(0, o.ic); ig.addColorStop(0.75, '#1a0c06'); ig.addColorStop(1, '#0a0403');
        lctx.fillStyle = ig; lctx.beginPath(); lctx.arc(o.lx, o.ly, ir, 0, TAU); lctx.fill();
        var dil = 0.62 + 0.3 * Math.sin(t * (1 + 4 * e) * 1.3 + o.ph) + (calm ? 0 : e * 0.15 * Math.sin(t * 17 + o.ph));
        lctx.fillStyle = '#000'; lctx.beginPath(); lctx.arc(o.lx, o.ly, ir * 0.42 * clamp(dil, 0.3, 1.1), 0, TAU); lctx.fill();
        lctx.fillStyle = 'rgba(255,255,255,0.85)'; lctx.beginPath(); lctx.arc(o.lx - ir * 0.32, o.ly - ir * 0.34, ir * 0.18, 0, TAU); lctx.fill();
        lctx.restore();

        lctx.strokeStyle = '#2a0508'; lctx.lineWidth = Math.max(1.5, R * 0.13);
        lctx.beginPath(); lctx.ellipse(0, 0, rx, ry, 0, 0, TAU); lctx.stroke();
        lctx.restore();
      }

      function drawBulges(t, now) {
        for (var i = 0; i < bulges.length; i++) {
          var b = bulges[i];
          var p = 1 + 0.12 * Math.sin(t * b.sp * (1 + 2.5 * e) + b.ph);
          var g = lctx.createRadialGradient(b.x, b.y, 0, b.x, b.y, b.r * p);
          if (b.dark) { g.addColorStop(0, 'rgba(50,4,10,' + (0.28 + 0.12 * e) + ')'); g.addColorStop(1, 'rgba(50,4,10,0)'); }
          else { g.addColorStop(0, 'rgba(240,160,150,' + (0.1 + 0.05 * Math.sin(t * b.sp + b.ph)) + ')'); g.addColorStop(1, 'rgba(240,160,150,0)'); }
          lctx.fillStyle = g; lctx.beginPath(); lctx.arc(b.x, b.y, b.r * p, 0, TAU); lctx.fill();
        }
      }

      var last = performance.now();
      function frame(now) {
        requestAnimationFrame(frame);
        var dt = Math.min(0.05, (now - last) / 1000); last = now;
        var tScale = calm ? 0.6 : 1;
        var t = now / 1000 * tScale;
        var fm = 1 + (calm ? 0.4 : 2.8) * e;
        var am = 1 + (calm ? 0.3 : 1.5) * e;
        var K = 0.9 + (calm ? 0.2 : 0.8) * e;
        var cm = calm ? 0.5 : 1;

        var tLimbs = Math.max(3, Math.round((4 + 16 * e) * cm));
        var tEyes = Math.max(3, Math.round((7 + 27 * e) * cm));
        var i, n = 0;
        for (i = 0; i < limbs.length; i++) if (!limbs[i].dying) n++;
        if (n < tLimbs && now - lastLimb > 380) { limbs.push(makeLimb(now)); lastLimb = now; }
        else if (n > tLimbs) { for (i = 0; i < limbs.length; i++) if (!limbs[i].dying) { limbs[i].dying = true; break; } }
        n = 0; for (i = 0; i < eyes.length; i++) if (!eyes[i].dying) n++;
        if (n < tEyes && now - lastEye > 140) { eyes.push(makeEye(now)); lastEye = now; }
        else if (n > tEyes) { for (i = 0; i < eyes.length; i++) if (!eyes[i].dying) { eyes[i].dying = true; eyes[i].dieAt = now; break; } }

        lctx.clearRect(0, 0, W, H);
        drawBulges(t, now);

        for (i = eyes.length - 1; i >= 0; i--) {
          if (eyes[i].dying && now - eyes[i].dieAt > 400) { eyes.splice(i, 1); continue; }
          drawEye(eyes[i], now, t);
        }
        for (i = limbs.length - 1; i >= 0; i--) {
          var l = limbs[i];
          if (l.dying) { l.reach -= dt * 0.6; if (l.reach <= 0) { limbs.splice(i, 1); continue; } }
          else if (l.reach < 1) l.reach += dt * 0.45;
          if (!calm && Math.random() < e * 0.012) l.sp = 1;
          l.sp *= 0.9;
          drawLimb(l, t, am, fm, K);
        }

        if (!calm && e > 0.45 && Math.random() < e * 0.05) {
          container.style.transform = 'translate(' + (rand(-2.5, 2.5) * e).toFixed(1) + 'px,' + (rand(-2.5, 2.5) * e).toFixed(1) + 'px)';
        } else if (container.style.transform) container.style.transform = '';
      }

      var rt = null;
      resizeAll();
      setTimeout(buildStatic, 30);
      requestAnimationFrame(frame);
      window.addEventListener('resize', function () { clearTimeout(rt); rt = setTimeout(function () { resizeAll(); buildStatic(); }, 300); });
      updateProgress();
    })();
