    <!-- OVERVIEW -->
    <div class="section-label agev">Overview</div>
    <div class="block age tear">
      <p>LD-096 is a humanoid female entity resembling a young woman dressed in traditional dark clothing.</p>
      <p>The entity possesses extremely pale skin, dark hair, and permanently closed eyes covered by what appears to be <strong>solidified candle wax</strong>.</p>
      <p>The wax does not appear to be physically attached to the entity's eyelids. Attempts to remove it have consistently failed, as the wax immediately reforms.</p>
      <p>Despite being apparently unable to see, LD-096 demonstrates complete awareness of its surroundings.</p>
      <p>The entity is consistently calm and displays a gentle, almost melancholic personality.</p>
      <p>LD-096 has shown no natural tendency toward violence.</p>
      <p>It frequently spends its time sitting quietly within its containment area, praying, sleeping, or interacting with D.I.V.I.D.E. personnel who voluntarily approach it.</p>
      <p>LD-096 has repeatedly referred to humans as:</p>
    </div>
    <div class="quote-box age tear"><div class="quote-text">“The people I was meant to save.”</div></div>

    <div class="divider agev" data-n="5"></div>

    <!-- BLESSING -->
    <div class="section-label agev">Primary Anomalous Property — The Blessing</div>
    <div class="block age tear">
      <p>LD-096 is capable of granting a temporary anomalous blessing to a living individual.</p>
      <p>The blessing is most commonly administered through physical contact, with LD-096 generally embracing the recipient.</p>
      <p>During the process, the entity emits a bright <strong>yellow-golden light</strong>.</p>
      <p>The recipient reports feeling an extreme sense of warmth, calmness, and safety.</p>
    </div>

    <div class="widget age tear">
      <div class="bless" id="blessBox">
        <div id="blessFig"></div>
        <div class="bless-text" id="blessText">
          <div class="state" id="blessState">Three arrows. Every breath is pain.</div>
          <div class="words"><span>Warmth</span><span>Calmness</span><span>Safety</span></div>
          <button class="btn" id="blessBtn" type="button">&#10022; Receive the blessing</button>
        </div>
      </div>
    </div>

    <div class="block age tear">
      <p>The blessing appears to bind LD-096's anomalous properties to the recipient.</p>
      <p>Once blessed, the individual becomes capable of being <strong>revived by LD-096 after death.</strong></p>
      <p>The revival does not require LD-096 to be physically present at the location of death.</p>
      <p>When a blessed individual dies, their body disappears and reappears near LD-096 after an unknown period of time.</p>
      <p>The exact mechanics behind this process remain unknown.</p>
    </div>

    <!-- LIMITATIONS -->
    <div class="section-label agev">Limitations of the Blessing</div>
    <div class="block age tear">
      <p>LD-096 cannot resurrect an individual indefinitely.</p>
      <p>Current testing indicates that a single person can survive a maximum of approximately <strong>five revivals</strong>.</p>
      <p>Every subsequent revival causes progressively greater deterioration.</p>
      <p>The deterioration appears to affect both the body and the individual's anomalous stability.</p>
    </div>

    <div class="widget age tear">
      <div class="rev rev-wrap s0" id="revWrap">
        <div id="revFig"></div>
        <div>
          <div class="rev-btns" id="revBtns"></div>
          <div class="rev-cap" id="revCap"></div>
        </div>
      </div>
    </div>

    <div class="sub-label agev">First Revival</div>
    <div class="block age tear"><p>Generally produces no permanent physical changes.</p><p>The individual may experience:</p></div>
    <div class="li age"><span class="mk">✦</span>extreme exhaustion</div>
    <div class="li age"><span class="mk">✦</span>temporary confusion</div>
    <div class="li age"><span class="mk">✦</span>intense fear</div>
    <div class="li age"><span class="mk">✦</span>vivid memories of their death</div>

    <div class="sub-label agev">Second Revival</div>
    <div class="block age tear"><p>Minor physical abnormalities begin appearing.</p><p>These may include:</p></div>
    <div class="li age"><span class="mk">✦</span>abnormal muscle growth</div>
    <div class="li age"><span class="mk">✦</span>discoloration of the skin</div>
    <div class="li age"><span class="mk">✦</span>changes in the eyes</div>
    <div class="li age"><span class="mk">✦</span>increased aggression</div>
    <div class="li age"><span class="mk">✦</span>involuntary tremors</div>

    <div class="sub-label agev">Third Revival</div>
    <div class="block age tear"><p>The individual's body begins undergoing significant transformation.</p><p>Subjects may develop:</p></div>
    <div class="li age"><span class="mk">✦</span>enlarged limbs</div>
    <div class="li age"><span class="mk">✦</span>abnormal bone growth</div>
    <div class="li age"><span class="mk">✦</span>distorted hands</div>
    <div class="li age"><span class="mk">✦</span>sharpened teeth</div>
    <div class="li age"><span class="mk">✦</span>increased physical strength</div>
    <div class="block age tear" style="margin-top:6px;"><p>Psychological deterioration also becomes significantly more apparent.</p></div>

    <div class="sub-label agev">Fourth Revival</div>
    <div class="block age tear"><p>The subject begins displaying increasingly animalistic behavior.</p><p>Communication becomes difficult.</p><p>The individual may experience:</p></div>
    <div class="li age"><span class="mk">✦</span>uncontrollable rage</div>
    <div class="li age"><span class="mk">✦</span>extreme paranoia</div>
    <div class="li age"><span class="mk">✦</span>loss of empathy</div>
    <div class="li age"><span class="mk">✦</span>compulsive aggression</div>
    <div class="li age"><span class="mk">✦</span>distorted vocalizations</div>

    <div class="sub-label agev">Fifth Revival</div>
    <div class="block age tear">
      <p>The individual is considered <strong>critically unstable</strong>.</p>
      <p>The human body can no longer properly contain the accumulated anomalous influence.</p>
      <p>Death during this stage is expected to result in complete transformation into <strong>LD-096-1.</strong></p>
    </div>

    <div class="divider agev" data-n="5"></div>

    <!-- DESPAIR BEAST -->
    <div class="section-label agev">LD-096-1 — “The Despair Beast”</div>
    <div class="block age tear">
      <p>LD-096-1 is the result of a blessed individual exceeding the safe limits of LD-096's resurrection ability.</p>
      <p>The resulting entity bears little resemblance to its original human form.</p>
      <p>The body becomes heavily distorted, with enlarged limbs, abnormal skeletal structures, excessive muscle growth, and other mutations unique to the individual.</p>
      <p>No two instances of LD-096-1 are expected to look identical.</p>
      <p>The transformation appears to be influenced by the individual's accumulated psychological suffering and experiences.</p>
      <p>For this reason, D.I.V.I.D.E. researchers have unofficially designated the resulting entities as:</p>
    </div>
    <div class="quote-box age tear"><div class="quote-text">“Beasts of Despair.”</div></div>
    <div class="block age tear">
      <p>LD-096-1 instances retain fragments of the original individual's memories but are generally incapable of rational communication.</p>
      <p>Their primary behavior is to attack and kill living organisms in their surroundings.</p>
      <p><strong>LD-096 itself is universally ignored by LD-096-1.</strong></p>
      <p>The entity will not attack its creator under normal circumstances.</p>
      <p>LD-096-1 remains classified as <strong>Tier II</strong> because the resulting creatures, despite their extreme aggression, are physically vulnerable.</p>
      <p>Standard firearms have proven effective against confirmed instances.</p>
    </div>

    <!-- HEALING -->
    <div class="section-label agev">Healing Ability</div>
    <div class="block age tear">
      <p>LD-096 possesses a limited healing ability separate from its resurrection blessing.</p>
      <p>Through direct contact, LD-096 can accelerate the natural healing process of living organisms.</p>
      <p>Minor wounds can be healed within seconds.</p>
      <p>More severe injuries require significantly longer contact.</p>
      <p>The ability cannot:</p>
    </div>
    <div class="li age x"><span class="mk">✕</span>regenerate completely destroyed organs</div>
    <div class="li age x"><span class="mk">✕</span>reverse advanced disease</div>
    <div class="li age x"><span class="mk">✕</span>restore a completely destroyed brain</div>
    <div class="li age x"><span class="mk">✕</span>resurrect the dead without the Blessing</div>
    <div class="li age x"><span class="mk">✕</span>repair severe anomalous corruption</div>
    <div class="block age tear" style="margin-top:6px;">
      <p>The entity appears to deliberately limit its healing ability.</p>
      <p>When asked why, LD-096 reportedly answered:</p>
    </div>
    <div class="quote-box age tear"><div class="quote-text">“Some things must be allowed to end.”</div></div>

    <!-- DURABILITY -->
    <div class="section-label agev">LD-096's Own Durability</div>
    <div class="block age tear">
      <p>Despite possessing anomalous abilities capable of resurrecting others, LD-096 itself is extraordinarily fragile.</p>
      <p>The entity possesses approximately human-level physical durability.</p>
      <p>A knife, firearm, blunt-force trauma, or even sufficiently powerful physical assault can kill LD-096.</p>
      <p>This vulnerability appears to be intentional rather than accidental.</p>
      <p>When killed, LD-096 does not remain dead.</p>
      <p>The entity eventually reappears at an unknown location somewhere on Earth.</p>
      <p>The location appears to be completely random.</p>
      <p>D.I.V.I.D.E. has been unable to determine whether LD-096 chooses its new location or whether the process is automatic.</p>
    </div>

    <div class="divider agev" data-n="5"></div>

    <!-- SEVENTH DEATH -->
    <div class="section-label agev">The Seventh Death</div>
    <div class="block age tear">
      <p>LD-096 has been successfully killed multiple times during controlled testing.</p>
      <p>However, researchers have established a strict prohibition against allowing LD-096 to die <strong>seven times.</strong></p>
      <p>The consequences of a seventh death remain unknown.</p>
      <p>LD-096 itself becomes visibly distressed whenever the subject is mentioned.</p>
    </div>

    <div class="seven-wrap age tear">
      <div class="seven" id="seven"></div>

      <p>When asked what would happen after its seventh death, the entity remained silent for approximately seventeen seconds before responding:</p>
    </div>
    <div class="quote-box age tear"><div class="quote-text">“I don't know.”</div></div>
    <div class="block age tear"><p>When asked whether the world would be safe, LD-096 responded:</p></div>
    <div class="quote-box age tear"><div class="quote-text">“No.”</div></div>
    <div class="block age tear">
      <p>No further explanation was provided.</p>
      <p>D.I.V.I.D.E. researchers currently theorize that the seventh death would cause a fundamental change in LD-096's anomalous nature.</p>
      <p>Several theoretical models predict the resulting entity could potentially reach <strong>Tier V classification.</strong></p>
      <p>This remains entirely speculative.</p>
      <p><strong>Under no circumstances is LD-096 to be intentionally killed seven times.</strong></p>
    </div>

    <!-- CONTAINMENT -->
    <div class="section-label agev">Containment Procedure</div>
    <div class="block age tear">
      <p>LD-096 is housed within a comfortable humanoid containment chamber rather than a conventional reinforced cell.</p>
      <p>The chamber contains:</p>
    </div>
    <div class="li age"><span class="mk">✦</span>sleeping quarters</div>

    <div class="li age"><span class="mk">✦</span>recreational materials</div>

      <p>The operator had previously received LD-096's blessing.</p>
      <p>Approximately several minutes after his death, the operator reappeared directly inside LD-096's containment chamber.</p>
      <p>The individual was alive.</p>
      <p>LD-096 immediately approached him.</p>
      <p>Instead of expressing relief, the operator began screaming.</p>
    </div>
    <div class="quote-box age tear"><div class="quote-text">“MONSTER! DEMON!”</div></div>
    <div class="block age tear">

      <p>LD-096 appeared confused and visibly distressed.</p>
      <p>The operator was later cleared for active duty following psychological evaluation.</p>
    </div>

            var pillar = Math.random() < 0.38, w = (pillar ? rand(26, 44) : rand(10, 24)) * sc;
            var h0 = Math.min((pillar ? rand(60, 170) : rand(90, 250)) * sc, sd.y - 60);
            var wx = WAX[(Math.random() * WAX.length) | 0], drips = [], nd = 2 + ((w / 9) | 0), q;
            for (q = 0; q < nd; q++) drips.push({ ox: rand(0.12, 0.88), len: rand(0.12, 0.5), th: rand(2, 4.6) * sc });
            candles.push({
              x: x + w / 2, y: sd.y, w: w, h0: h0, m: rand(0.55, 1), th: 0, fs: rand(0.85, 1.2) * sc, ph: rand(0, TAU), fa: 1,
              smoked: false, drips: drips, shelf: si, last: 0,
              cDark: rgb(wx, 0.6), cMid: rgb(wx, 1), cLight: rgb(wx, 1.1), cDeep: rgb(wx, 0.48), cStain: rgb(wx, 0.8)
            });
            x += w + rand(10, 46) * sc;
          }
        });
        var bestA = null, bestB = null, da = 1e9, db = 1e9;
        candles.forEach(function (c) {
          if (c.shelf !== 0) return;
          var a = Math.abs(c.x - W * 0.12), b = Math.abs(c.x - W * 0.88);
          if (a < da) { da = a; bestA = c; } if (b < db) { db = b; bestB = c; }
        });
        if (bestA) bestA.last = 1;
        if (bestB && bestB !== bestA) bestB.last = 2;
        var rest = candles.filter(function (c) { return !c.last; });
        for (var i = rest.length - 1; i > 0; i--) { var j = (Math.random() * (i + 1)) | 0, t = rest[i]; rest[i] = rest[j]; rest[j] = t; }
        rest.forEach(function (c, idx) { c.th = 0.06 + 0.9 * (idx / Math.max(1, rest.length - 1)); });
        if (bestA) bestA.th = 9;
        if (bestB && bestB !== bestA) bestB.th = 0.985;

        motes = [];
        for (var m = 0; m < 90; m++) { var mo = {}; resetMote(mo, true); motes.push(mo); }
        smokes = [];
      }

      function resetMote(m, init) {
        m.ash = Math.random() < Math.pow(ds, 0.9);
        m.x = rand(0, W);
        m.y = init ? rand(0, H) : (m.ash ? -10 : H + 10);
        m.sz = m.ash ? rand(1.2, 3.2) : rand(0.8, 2.4);
        m.vy = m.ash ? rand(10, 26) : -rand(6, 16);
        m.vx = rand(-6, 6);
        m.ph = rand(0, TAU);
        m.a = rand(0.25, 0.7);
      }

      function shelfDraw(sh) {
        var th = 14 * sc, x0 = Math.max(0, sh.x0), x1 = Math.min(W, sh.x1);
        var g = lc.createLinearGradient(0, sh.y, 0, sh.y + th);
        g.addColorStop(0, '#5a4026'); g.addColorStop(0.15, '#3e2a16'); g.addColorStop(1, '#1a0f08');
        lc.fillStyle = g; lc.fillRect(x0, sh.y, x1 - x0, th);
        lc.fillStyle = 'rgba(255,220,150,0.18)'; lc.fillRect(x0, sh.y, x1 - x0, 1.5);
        lc.fillStyle = 'rgba(0,0,0,0.5)'; lc.fillRect(x0, sh.y + th, x1 - x0, 5 * sc);
        for (var i = 0; i < sh.stains.length; i++) {
          var st = sh.stains[i];
          lc.fillStyle = 'rgba(230,210,170,' + (0.1 + 0.4 * ds) + ')';
          lc.beginPath(); lc.ellipse(st.x, sh.y + 1, st.r * (0.6 + ds), 2.6 * sc * (0.6 + ds), 0, 0, TAU); lc.fill();
        }
      }

      function candleBody(c) {
        var melt = clamp(ds * c.m * 1.15, 0, 1) * 0.8;
        var h = Math.max(8 * sc, c.h0 * (1 - melt));
        c.h = h; c.melt = melt; c.top = c.y - h;
        var x = c.x, y = c.y, w = c.w, top = c.top;
        var pw = w * (0.55 + melt * 1.1) + w * 0.45;
        lc.fillStyle = '#6a4a22'; lc.beginPath(); lc.ellipse(x, y - 1, w * 0.95 + 2, 3.6 * sc, 0, 0, TAU); lc.fill();
        lc.fillStyle = c.cStain; lc.beginPath(); lc.ellipse(x, y - 1, pw, (2.2 + melt * 5) * sc, 0, 0, TAU); lc.fill();
        var g = lc.createLinearGradient(x - w / 2, 0, x + w / 2, 0);
        g.addColorStop(0, c.cDark); g.addColorStop(0.35, c.cMid); g.addColorStop(0.62, c.cLight); g.addColorStop(1, c.cDeep);
        lc.fillStyle = g;
        lc.beginPath(); lc.moveTo(x - w / 2, top); lc.lineTo(x + w / 2, top); lc.lineTo(x + w / 2, y - 2);
        lc.quadraticCurveTo(x + w / 2, y, x + w / 2 - 3, y); lc.lineTo(x - w / 2 + 3, y); lc.quadraticCurveTo(x - w / 2, y, x - w / 2, y - 2); lc.closePath(); lc.fill();
        for (var i = 0; i < c.drips.length; i++) {
          var dr = c.drips[i], len = Math.min(h * 0.92, c.h0 * dr.len * (0.35 + melt * 1.6)), dx = x - w / 2 + dr.ox * w;
          lc.strokeStyle = c.cLight; lc.lineWidth = dr.th; lc.lineCap = 'round';
          lc.beginPath(); lc.moveTo(dx, top + 2); lc.lineTo(dx, top + 2 + len); lc.stroke();
          lc.fillStyle = c.cLight; lc.beginPath(); lc.arc(dx, top + 2 + len, dr.th * 0.75, 0, TAU); lc.fill();
        }
        var ry = Math.max(2, w * 0.12);
        lc.fillStyle = c.cLight; lc.beginPath(); lc.ellipse(x, top, w / 2, ry, 0, 0, TAU); lc.fill();
        lc.fillStyle = 'rgba(255,214,140,' + (0.55 * c.fa) + ')'; lc.beginPath(); lc.ellipse(x, top, w * 0.34, ry * 0.62, 0, 0, TAU); lc.fill();
        lc.strokeStyle = '#1a0f08'; lc.lineWidth = 1.6; lc.beginPath(); lc.moveTo(x, top); lc.lineTo(x, top - 6 * sc); lc.stroke();
      }

      function candleFlame(c, t) {
        var target = (ds < c.th) ? 1 : 0;
        var prev = c.fa;
        c.fa += (target - c.fa) * 0.06;
        if (prev > 0.5 && c.fa <= 0.5 && !c.smoked) { c.smoked = true; for (var i = 0; i < 7; i++) smokes.push({ x: c.x, y: c.top, birth: nowT + i * 260, life: 3600 + rand(0, 1200), vx: rand(-6, 6), r: rand(5, 10) * sc, ph: rand(0, TAU) }); }
        if (c.fa > 0.5) c.smoked = false;
        if (c.fa < 0.02) return;
        var fl = 1 + (0.10 + 0.28 * ds) * Math.sin(t * (7 + 3 * ds) + c.ph) + (0.05 + 0.2 * ds) * Math.sin(t * 13.7 + c.ph * 2.3);
        var sway = (Math.sin(t * 2.1 + c.ph) * 0.08 + Math.sin(t * 5.3 + c.ph * 1.7) * 0.06) * (1 + 3 * ds);
        var size = c.fs * 30 * (1 - 0.42 * ds) * fl;
        var kcold = c.last === 1 ? clamp((ds - 0.88) / 0.1, 0, 1) : 0;
        var fy = c.top - 6 * sc;
        var halo = size * 8 * (1 - 0.35 * ds);
        lc.save(); lc.globalCompositeOperation = 'lighter';
        lc.globalAlpha = c.fa * 0.30 * (1 - 0.6 * ds) * (1 - kcold);
        lc.drawImage(GL, c.x - halo, fy - size * 0.5 - halo, halo * 2, halo * 2);
        if (kcold > 0) { lc.globalAlpha = c.fa * 0.34 * kcold; lc.drawImage(GC, c.x - halo, fy - size * 0.5 - halo, halo * 2, halo * 2); }
        lc.translate(c.x, fy); lc.rotate(sway);
        lc.globalAlpha = c.fa * (0.95 - 0.2 * ds) * (1 - kcold);
        lc.drawImage(FL, -size * 0.28, -size, size * 0.56, size);
        if (kcold > 0) { lc.globalAlpha = c.fa * kcold; lc.drawImage(FC, -size * 0.28, -size, size * 0.56, size); }
        lc.restore();
      }

      function drawMotes(dt, t) {
        for (var i = 0; i < motes.length; i++) {
          var m = motes[i];
          m.y += m.vy * dt; m.x += (m.vx + Math.sin(t * 0.8 + m.ph) * 8) * dt;
          if (m.y < -20 || m.y > H + 20 || m.x < -20 || m.x > W + 20) { resetMote(m, false); continue; }
          if (!m.ash) {
            lc.save(); lc.globalCompositeOperation = 'lighter'; lc.globalAlpha = m.a * (1 - ds) * (0.6 + 0.4 * Math.sin(t * 2 + m.ph));
            var s = m.sz * 7; lc.drawImage(GL, m.x - s, m.y - s, s * 2, s * 2); lc.restore();
          } else {
            lc.save(); lc.globalAlpha = m.a * 0.7; lc.fillStyle = 'rgb(150,145,140)';
            lc.translate(m.x, m.y); lc.rotate(t * 0.6 + m.ph); lc.fillRect(-m.sz, -m.sz * 0.6, m.sz * 2, m.sz * 1.2); lc.restore();
          }
        }
      }
      function drawSmoke(now) {
        for (var i = smokes.length - 1; i >= 0; i--) {
          var s = smokes[i];
          if (now < s.birth) continue;
          var age = (now - s.birth) / s.life;
          if (age >= 1) { smokes.splice(i, 1); continue; }
          var x = s.x + Math.sin(age * 6 + s.ph) * 14 * age + s.vx * age, y = s.y - age * 150 * sc, r = s.r * (1 + age * 3);
          lc.save(); lc.globalAlpha = (1 - age) * 0.26; lc.drawImage(SM, x - r, y - r, r * 2, r * 2); lc.restore();
        }
      }

      var last = performance.now();
      var lightsEl = $('lightsVal'), lightsBox = $('lights');
      function frame(now) {
        requestAnimationFrame(frame);
        var dt = Math.min(0.05, (now - last) / 1000); last = now; nowT = now;
        ds += (d - ds) * Math.min(1, dt * 4);
        if (Math.abs(ds - shownD) > 0.002) { shownD = ds; root.style.setProperty('--d', ds.toFixed(3)); }
        var t = still ? 0 : now / 1000;
        lc.clearRect(0, 0, W, H);
        var i;
        for (i = 0; i < shelves.length; i++) shelfDraw(shelves[i]);
        for (i = 0; i < candles.length; i++) candleBody(candles[i]);
        var litN = 0;
        for (i = 0; i < candles.length; i++) { candleFlame(candles[i], t); if (candles[i].fa > 0.5) litN++; }
        if (!still) drawMotes(dt, t);
        drawSmoke(now);
        if (litN !== lastLit) { lastLit = litN; lightsEl.textContent = litN + ' / ' + candles.length; lightsBox.classList.toggle('low', litN <= Math.max(2, candles.length * 0.15)); }
      }

      }
